  `project_interfaces/srv/InspectBasket.srv`

  - 권장안은 `foreign_count`를 별도 필드로 추가하고 `normal_count` 불변식
    `0 <= normal_count <= total_count`를 보장하는 것이다.
  - 음수 입력, `defect_count > total_count`, 이물질만 있는 경우를 검증한다.
- **완료 조건:** 모든 유효한 검사 결과에서 개수 필드가 의미와 수학적 불변식을
  만족하며 ROS2 서비스와 dataclass가 동일한 규격을 사용한다.

  - 테스트 의존성을 lock하거나 재현 가능한 개발 설치 절차를 제공한다.
- **완료 조건:** 모든 PR에서 동일한 명령으로 품질 검사가 자동 실행되고, 실패한
  검사 없이는 병합되지 않는다.

### [ ] 설치본에서 설정·웨이포인트 리소스 확인

- **소유 패키지:** `vision_inspection`, `omx2_sorting`, `system_monitor`
- **현재 문제:** 소스 또는 editable 설치에서는 config 파일을 찾지만, 일반 wheel과
  colcon 설치본에서 `class_scheme.yaml` 및 OMX2 waypoint 경로가 유지되는지 검증이
  없다. `omx2_sorting`은 아직 ROS2 패키지도 아니다.
- **할 일:**
  - 설정 파일을 package data 또는 ROS share 경로로 설치한다.
  - 소스 실행, editable 설치, wheel 설치, colcon 설치 각각에서 리소스 탐색을
    테스트한다.
  - 장비별 웨이포인트를 배포 기본값과 현장 교시값으로 분리할지 결정한다.
- **완료 조건:** 어떤 지원 실행 방식에서도 필요한 리소스를 동일한 규칙으로 찾고,
  파일이 없을 때 실행 전에 명확히 실패한다.

### [ ] 문서와 구현 상태 동기화

- **소유 패키지:** 각 패키지 README, 전체 상태는 `system_coordinator`

### [ ] 중복 코드와 광범위 예외 처리 정리

- **소유 패키지:** `omx2_sorting`, `system_monitor`
- **현재 문제:** PASS/REJECT 모션에 경로 상수 정의가 중복되어 있고 두 실행기가

  사라지지 않는다.

## 검증 기록

리뷰 당시 다음 항목을 확인했다.

- Python `compileall`: 통과
- 주요 애플리케이션 및 패키지 import: 통과
- `pip check`: 의존성 충돌 없음
- pytest: 저장소 `.venv`에 `pytest`가 없어 미실행
- ROS2/colcon: 현재 환경에 실행 도구가 없어 미실행
- 실제 카메라·OMX 하드웨어: 미검증

위 검증 기록은 구현 완료 증명이 아니다. 특히 실제 자동 운전 승인은 P0 항목과
하드웨어 검증을 모두 마친 뒤 별도로 판단해야 한다.
